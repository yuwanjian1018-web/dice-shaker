# 骰子点样式修正 · 2026-09-05

此版本作为历史保留。用户随后提供参考并要求保留宝石高光、进一步加大点与骰身，当前版本见 `design/fuller-pips-20260905/README.md`。

本轮替换六张运行骰子素材，修正 2 点的面内对角排列并加大红蓝点。骰子位置、盘沿、体感和按钮逻辑沿用上一轮。

- 顶面 2 点置于菱形投影的左右对角内侧；3 点也改为面内对角线上的两端及中心。由于相机正对立方体的一条立边，顶面这条对角线在屏幕上接近水平；判断依据是骰面四角，而非屏幕方向。
- 红色 1 点、红色 4 点和全部蓝点均加大；侧面的 2 点逐面核对，保留对角布置。
- 运行资源：`assets/dice-perspective/die-1.png` 至 `die-6.png`，仍为 240 × 240 透明 PNG。
- 使用内置 ImageGen 编辑原骰子图集。原始输出保存在 `dice-atlas-green.png`，两轮提示词见 `prompts.md`。未使用 API CLI。脚本仅进行色键提取、裁切、缩放和透明补边。
- 重建：设置 `DICE_SHARP_MODULE` 指向 sharp 后，执行 `node scripts/build-perspective-dice.js --dice-only`。不带该选项时还会从上一轮保留的源图重建托盘。
