# 骰子 3D 模型：哑光内凹球面点

更新日期：2026-09-07。状态：外观建模与交互预览，尚未接入小程序。

依据当前实际运行的 `assets/dice-perspective/die-1.png` 至 `die-6.png` 建模。模型保留白色圆角骰身、1/4 面红点、其余蓝点。本次按用户要求，将彩色点改为凹孔内的平滑哑光球面，中心向内凹，去掉宝石切面。图片无法唯一确定真实曲面和材质参数，因此这是按视觉重建的可编辑模型。

## 文件

- `ivory-matte-dice.blend`：当前 Blender 5.0.1 可编辑源文件，包含骰身、21 个独立球面点、预览灯光和相机。
- `ivory-matte-dice.glb`：当前可供三维引擎加载的模型，不包含相机和预览灯光。
- `ivory-jewel-dice.blend`、`ivory-jewel-dice.glb`：保留的旧版切面模型，不是当前版本。
- `build_model.py`：可重复生成模型的参数化脚本。
- `reference-angle.png`、`clear-top-angle.png`：同一个真实模型在 30° / 50° 观看高度下的渲染。
- `face-1.png` 至 `face-6.png`：交互预览中的六种朝向；`interactive-preview.png` 是默认五点朝上的视图。
- `model-manifest.json`：原始素材 SHA-256、面法向、21 个点位和导出尺寸。
- `preview-check.json`：浏览器加载、六面切换与观看角度控制的检查结果。

## 模型约定

六个面完整建模，共 21 点；相对面是 1/6、2/5、3/4。初始 Blender 朝向为 +Z=1、-Y=2、+X=3，右手性与当前图片一致。

预览的顶面/左面/右面依次为：1/2/3、2/3/1、3/1/2、4/2/1、5/1/3、6/3/2。

骰身为真实圆角网格，点孔通过布尔差集形成。彩色点使用连续的内凹球面，中心低于边缘，边缘低于骰身表面，配合平滑着色和朝向凹腔的球面法线。重建时逐个检查 21 个点的径向曲面高度，确保从中心向边缘升高，且不与白色孔底相交。红蓝材质粗糙度 0.82、金属度 0、清漆强度 0，保留柔和的明暗变化。

导出 19,596 个三角面，GLB 403,520 字节，22 个网格；这是外观预览版，正式用于多骰子实时渲染时还需合并绘制、测量包体和验证手机性能。当前没有给小程序增加三维引擎，也没有替换原素材。

浏览器检查：六面均加载成功，拖动旋转能改变观看角度，角度滑块可调整至 55°，无页面脚本错误；已查看桌面和手机宽度截图，以及 Blender 渲染中的球面外观。
